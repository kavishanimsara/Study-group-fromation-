STUDY GROUP FORMATION RESEARCH PROJECT
======================================

WHAT IS INCLUDED
----------------
- Revised_Study_Group_Formation_Report.docx: revised report following the assignment structure.
- replicate_experiment.py: executable experiment; creates synthetic data, runs baselines and the proposed heuristic, and exports results/figures.
- build_report.py: source script used to produce the Word report from the experiment outputs.
- requirements.txt: required Python packages.
- outputs/: CSV results, synthetic example data, experiment configuration, and PNG figures.

IMPORTANT RESEARCH TRANSPARENCY
-------------------------------
No interviews, surveys, or real student records were collected. The experiment uses synthetic data generated by the included script. The numerical findings in the report are actual outputs from running that script, but they are not measurements from a real classroom. Do not relabel them as interview findings or real student evidence.

RUN THE EXPERIMENT ON WINDOWS
-----------------------------
1. Extract the ZIP file.
2. Open a terminal in the extracted project folder.
3. (Optional but recommended) Create and activate a virtual environment:
       py -m venv .venv
       .venv\Scripts\activate
4. Install dependencies:
       python -m pip install -r requirements.txt
5. Run:
       python replicate_experiment.py

The script writes or refreshes the outputs/ directory.

KEY OUTPUT FILES
----------------
- outputs/results_summary.csv: primary comparison table.
- outputs/results_by_instance.csv: metric values for each of the 30 synthetic instances.
- outputs/alpha_sensitivity_summary.csv: summary of the five alpha settings.
- outputs/alpha_sensitivity_by_instance.csv: sensitivity values for each instance.
- outputs/figure1_synthetic_network.png: example synthetic weighted graph.
- outputs/figure2_partition_comparison.png: the four example partitions.
- outputs/figure3_method_comparison.png: cohesion and imbalance comparison.
- outputs/figure4_alpha_sensitivity.png: sensitivity graph.
- outputs/example_synthetic_students.csv and outputs/example_synthetic_edges.csv: example data for the first instance.
- outputs/experiment_config.json: data generator and metric settings.

REPRODUCIBILITY
---------------
The script uses fixed seeds beginning with 20261016. Re-running unchanged code with the same package behavior should reproduce the metric results. Runtime measurements may vary by computer. If you alter the code, number of instances, random seed, or settings, regenerate the report's results before submission.
